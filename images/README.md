# Папка для изображений Gemini (`public/images/`)

Положите сюда сгенерированные в Gemini изображения (в формате `.webp`, `.png` или `.jpg`), и сайт автоматически отобразит их у всех посетителей после загрузки на GitHub Pages:

1. `hero-main.webp` (или `.png` / `.jpg`) — `16:9` · Фон главного блока Hero
2. `quest-th.webp` — `1:1` · Миниатюра станции `/θ/` (Одуванчик)
3. `quest-w.webp` — `1:1` · Миниатюра станции `/w/` (Именинная свечка)
4. `quest-r.webp` — `1:1` · Миниатюра станции `/r/` (Мягкий львёнок)
5. `trust-portrait.webp` — `3:4` · Центральная наклонная карточка во 2-й секции
6. `facility-articulation.webp` — `3:4` · Карточка «Лаборатория Артикуляции»
7. `facility-echo.webp` — `3:4` · Карточка «Арена Голосового Эха»
8. `atlas-banner.webp` — `16:9` · Баннер в разделе «Атлас звуков»
9. `games-banner.webp` — `16:9` · Баннер в разделе «Игровая Арена»
